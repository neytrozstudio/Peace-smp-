Publish Peace SMP with GitHub Pages

Because this entire site lives in a single self-contained index.html file, hosting it on GitHub Pages takes only a few minutes.

  1. Step 1

    Create a Repository

    Create a new public repository on GitHub and upload this file named exactly index.html at the root.

  2. Step 2

    Enable GitHub Pages

    Open Settings → Pages, choose Deploy from a branch, select main and / (root), then save.

  3. Step 3

    Share & Keep Codes Private

    Visit your published Pages URL. Never paste plain-text verification code lists inside HTML files.
